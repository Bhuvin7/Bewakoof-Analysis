# Bewakoof — Business Intelligence Dashboard
## Power BI | DAX | Retail Analytics

![Dashboard](screenshot1.png)

## Project Overview
Built a 2-page interactive Power BI dashboard 
analyzing Bewakoof's sales performance and 
customer behavior across multiple channels.

## Key Metrics
- Total Revenue: ₹2.64M
- Total Orders: 3,000
- Gross Margin: 51.93%
- Repeat Customer Rate: 56.14%
- Cancellation Rate: 17.13%

## Key Insights
- D2C channel dominates with ₹0.94M revenue
- Anime category leads with ₹0.42M
- Hyderabad leads all cities in orders
- Unisex products generate highest revenue

## Dashboard Pages
### Page 1 — Sales Performance
- Revenue by Category, Channel, Month
- Gender split, Top 10 cities map
- KPI cards — Revenue, Orders, Margin

### Page 2 — Customer Analysis
- Orders by Franchise and Product Type
- Repeat Customer Rate — 56.14%
- Return Rate analysis
- Treemap — Top selling categories

## Tools Used
- Power BI Desktop
- DAX (35+ measures)
- Excel / CSV datasets
- Data Modeling

## Dataset
Synthetic dataset created for portfolio 
purposes — simulating Bewakoof's business 
operations across Products, Orders and 
Inventory tables.
